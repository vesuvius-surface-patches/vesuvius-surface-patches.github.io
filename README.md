# Held-out region explorer

The live page for [udemex10/vesuvius-surface-patches](https://github.com/udemex10/vesuvius-surface-patches): slide through 16 hand-labeled test regions of Vesuvius Scroll 1 and compare official GrowPatch with the tiled blend.

This repository only hosts the page. Its source, the data behind it and the tools that rebuild it live in the main repository's `docs/` and `tools/` folders.
